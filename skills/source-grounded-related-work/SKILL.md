# 逐句溯源的通用 Related Work 小段落写作

先选择可核对的论文原句，再压缩、综合成目标句。输出应能说明每项研究描述来自哪里。
默认中文解释、英文论文正文；语言、篇幅、数量和交付方式服从用户本次要求。

适用单位是任意学科论文Related Work中介绍一个相关研究方向的**小段落**。
根据该领域原文使用术语、研究对象和评价标准；不默认用户研究计算机、调度或模型服务。

## 范围与协作

- 先从用户给出的稿件、参考文献库和已确认的句子确认当前方向、核心论文及写到哪一句。
- 默认围绕一个方向的小段落工作；用户只指定其中一句时只完成该句。
  用户明确要求多个方向或完整章节时，再对各个段落分别应用本方法。
- 默认在会话中提供建议。用户要求写文件时才编辑稿件；文件和材料已有授权时直接读取。
- 已确认的句子原样保留。需要修改时，明确展示改动及理由；不能把“仅补引用”变成重写。
- 不预设段落数量、研究分类或领域，不把某篇论文的具体方法、路径或gap套到其他课题。

## 一个研究方向小段落的写法

### 1. 背景句：Introduction 原句 → 综合压缩 → 引用支撑

1. 从几篇核心论文的 **Introduction** 选出合计 **1–3句**介绍这一方向背景、现状或应用的原句。
   记录论文名、版本、章节、页码和段落；有检索能力时实际打开原始来源。
2. 提取这些句子的共同信息和必要术语，压缩、综合成 **一句背景介绍**。
   论断强度与原文一致：应用示例不能自动推出广泛采用，受欢迎不能自动写成主导范式。
3. 为背景句补齐 **至少6篇不同论文**的引用。指定核心论文能支撑该句时可以计入，
   不为凑数加入无关文献，也不因后面会介绍某篇论文而自动排除其背景引用。
4. 默认支撑文献来自可核验的领域顶会或 SCI 一区期刊；新增文献优先近两年，尽量不超过近四年。
   以执行时日期计算；用户选定的较早核心论文保留。用户调整标准时以新要求为准。
   不采用SCI分区或不以会议为主要发表渠道的学科，使用用户确认的同等严格的本领域标准；
   不能自行降低文献质量、数量或时效要求。
5. 对背景句的各个分句分别核对支撑，六篇引用无需每篇支持全部分句。
   少于六篇已核实文献时如实报告数量和缺项，不能把未核实候选当作已完成。

### 2. 举例句：每篇 Abstract / Introduction 原句 → 一句方法介绍

1. 每篇代表性论文，从其 **Abstract 和 Introduction** 选出 **1–2句**明确介绍自身方法的原句。
   方法可以是研究设计或分析框架，不限于算法；识别该研究自己的内容，避免把前人方案误写成其贡献。
2. 根据段落目的保留必要的信息：提出什么方法、采用什么机制、解决什么问题或优化什么目标。
   每篇压缩为 **一句话**，无需机械塞满所有信息或堆砌实验数字。
3. 保留准确技术名词、专业动词搭配和逻辑关系，重新组织句法并准确引用。
   不能把多个来源逐字拼接；不能把原文没有的目标、能力或因果关系补进来。
4. 默认以所选 Abstract / Introduction 原句支撑介绍。若关键细节只在方法章节出现，
   明示位置差异；用户同意扩大取材范围后再纳入该细节。

### 3. 收束句：比较研究范围 → 1–2句 research gap

1. 对照代表性工作实际处理的问题与目标论文的研究问题，选一个与本方向直接相关的缺口。
   从已有稿件确认目标问题；若仍缺少关键信息，只询问必要部分。
2. Gap 是作者的比较性归纳，明确区别于论文作者直接陈述的事实。
   不能仅凭 Abstract / Introduction 没有提及某机制就断定它不存在；涉及排除性论断时核查全文相关部分。
3. 用自然、克制、学术的英文写 **1–2句**，说明尚未明确处理的关系或适用边界。
   论断限定在已核查的工作及场景；证据不足时标为候选判断。
4. 检查gap是否与前文已介绍的研究内容、方法或发现矛盾。
   避免无证据的首次声明、全领域否定及无关的自身方法宣传。

## 每次交付

默认依次给出以下内容，并保持与当前句子范围相称：

1. **原文依据**：论文名、Abstract / Introduction、页码或段落、可访问链接或本地文件位置，
   以及实际选用的原句。引用长度受限时展示关键片段，清楚标注省略并保留完整定位；
   不把中文释义、摘录片段或检索摘要冒充完整原句。
2. **缩写与综合**：简述保留了什么、删去了什么，以及这些取舍如何服务当前句子。
3. **建议句子**：可直接使用的英文；用户需要时给出 LaTeX 及现有 citation keys。
4. **引用状态**：背景句交代已核实篇数及必要缺项；新增 BibTeX 仅在用户需要时输出。
   Gap 交代比较依据，无需伪造一个声称该 gap 的“原句”。

用户只要已确认句子的 LaTeX、BibTeX 或最终正文时，直接给所需内容，复用已核查证据，
不重新改写，也不重复展开全部过程。

查找背景支撑、核验分区、生成 BibTeX 或原文无法访问时，按需读取
[引用与来源核验](references/citation-verification.md)。
需要查看完整的取舍示范时读取[缩写示例](references/worked-example.md)。

## 交付前核对

- 每个研究描述能指向已读原文；事实、改写和比较推断分得清。
- 背景句来自 Introduction 的1–3句，并有至少6篇符合当前标准的已核实文献，或明确报告不足。
- 举例每篇一句，依据是该文 Abstract / Introduction 中介绍自身方法的1–2句。
- Gap 仅1–2句，范围准确，与前文和目标论文一致。
- 术语、语法及措辞自然，引用键可解析，已确认的文字和未授权编辑的文件保持原样。
