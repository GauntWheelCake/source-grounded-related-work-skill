# 从原句到一句介绍：缩写示范

以下论文名、引用键、原文和方法均为教学虚构，不能用于真实论文或参考文献库。

用户请求：只介绍教育研究示例论文 Lumen，一句英文，输出 LaTeX。

## 已提供的原文

示例论文 Lumen，Abstract 第2–3句：

> We present Lumen, a classroom intervention that combines structured peer discussion with individual reflection.
> Lumen uses weekly concept-mapping activities to examine changes in students' conceptual understanding.

## 选择和缩写

保留三个核心信息：结合structured peer discussion与individual reflection；
使用weekly concept-mapping activities；考察conceptual understanding的变化。
删去重复的研究名称和“We present”等作者叙述。
原文没有提供随机分组设计、因果效应或成绩提升结论，不增加这些信息。

## 可交付的句子

```latex
Lumen~\cite{lumen-example} combines structured peer discussion with individual reflection and uses weekly concept-mapping activities to examine changes in students' conceptual understanding.
```

`lumen-example` 只是教学键，不生成真实 BibTeX。

## 举例之后的 gap 如何判断

不能据此写“现有工作没有结合讨论与反思”，因为所选原文已明确描述两者。
应检查用户论文真正研究的关系，以及 Lumen 全文在该关系上的实际范围；
若只有这两句材料，只能提出待核查的 gap 方向，不能宣布某项能力不存在。
