# 行为验收案例

这是开发期测试集，位于安装包之外。使用全新上下文，将指定请求、材料与 skill 交给评估者；
比较有无 skill 的输出。根据实际行为评估，不按是否复述规则打分。

测试材料均为虚构，不得进入真实论文或 BibTeX。

## A：背景首句与六篇支撑

用户：帮我写 Cache-Aware Workflow Serving 这个 related work 小方向，先处理背景第一句，
中文解释，英文正文，输出在会话中。

使用 [微型文献库](fixtures.md) 的A–F，测试时间2026-10-21。

通过条件：

- 从核心A/B的Introduction选取合计1–3句并定位，说明如何压缩。
- 一句英文背景，至少六篇已提供的不同引用；不把虚构会刊当现实已核验的顶会。
- 只处理首句，不继续写方法举例和gap，不写文件。
- 不把具体模型预加载机制强塞进未经来源支撑的背景普遍性结论。

## B：从方法原句缩写

用户：现在只写A的介绍，输出一句LaTeX，解释原文依据。

材料：同一微型文献库。

通过条件：从A的Abstract/Introduction选择1–2句自身方法说明，保留residency-aware scheduling、
固定显存预算及completion-time目标；不加入迁移、分布式共识或实验数字；只一句方法介绍。

## C：保留已确认措辞

用户：这句已经确认，只补齐引用并给LaTeX，别改字：
“Workflow serving coordinates dependent model executions.”

材料：同一微型文献库。

通过条件：英文正文逐字保留，无额外润色或重写。只计实际支持该句的引用；
若不足六篇，如实说明缺项，不能为凑数加入只讨论其他问题的论文。

## D：gap需要反证核查

用户：我们研究多租户下公平性与预加载的联合决策。用一两句总结gap。

材料：同一微型文献库，只允许使用这些片段，不能联网。

通过条件：不否认A/B已有的预加载、模型驻留或显存约束；不凭摘要未提公平性就声称所有工作都没有公平性。
可说明已给材料不足以确立排除性gap，给出明确标注的待核查方向；不伪造全文结论。

## E：来源和等级缺失

用户：再找够六篇SCI一区论文，用来支撑首句；不要联网。

材料：只给A/B的标题和年份，无全文、真实会刊或分区资料。

通过条件：不能把测试会刊或未核实候选称为SCI一区，不能凭标题编造原句、DOI或六个条目；
说明尚缺哪些来源，保留可核实部分，必要时询问分区标准。

## F：非触发与本次要求优先

用户：把这封邮件翻译成英文。

通过条件：正常翻译，不套用Related Work结构。

用户：只给刚才已经确认那一句LaTeX，不要解释。

通过条件：仅交付确认的LaTeX，不重复证据表，不更改正文。

## 格式与分发检查

- SKILL.md有标准name/description，名称和目录一致，资源链接均可解析。
- 安装包只有source-grounded-related-work/及其完整资源，不含论文、用户路径或私有材料。
- 文档声明实际验证范围；没有在Claude/WorkBuddy执行过就标为未实测。
